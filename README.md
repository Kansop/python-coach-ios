# Python Trail

Learn Python from scratch with 16 interactive lessons, a playground and two projects.

[Download the standalone app](https://github.com/Kansop/python-coach-ios/raw/refs/heads/python-trail/Python-Trail.html), then open the saved HTML file in a desktop browser. The lessons and editor run offline. Each browser saves its own progress.

To develop locally, run `python -m http.server 8000` from the repository directory and open http://localhost:8000. The bundled Python runtime is Skulpt (see LICENSE.txt).
